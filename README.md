🎯 Project Goal

The goal is to:

Understand how people feel about gender equality initiatives (e.g., campaigns like #HeForShe, #MeToo).

Classify tweets into positive, neutral, or negative sentiment.

Visualise overall sentiment trends and possibly spotlight differences (e.g., over time, by topic).
🔧 Setup & Installation

To get the project running:

Clone the repository:

git clone https://github.com/kiruthiga781/gender-equality-sentiment-analysis.git
cd gender-equality-sentiment-analysis
🚀 Usage

Run the analysis script:

python sentiment_analysis.py


This will:

Load dataset/gender_equality_tweets.csv

Clean and preprocess tweets (removing URLs, mentions, punctuation, stop-words, etc.)

Apply sentiment analysis (e.g., using NLP libraries such as NLTK, TextBlob or VADER)

Label each tweet as Positive / Neutral / Negative

Generate and display results (counts, percentages, or graphs)
